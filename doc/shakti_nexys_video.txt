Shakti Class C Core in Nexys Video FPGA:

1. Setup OpenOCD to start communication between the FPGA and your linux system.

Steps to be followed:
	> cd into shakti_sdk/bsp/third_party/shaktiz
	> run sudo $(which openocd) -f ftdi.cfg

This should setup openocd listening at ports 3333, 6666

*Do not close this terminal*

2. Now there are the following cases to take into consideration:

	- This is where you choose your IP.
	- Case 1: Your IP is available with example code and Make file.
	- Case 2: Your IP is available with but not with example code.

Case 1:

> run make software PROGRAM=<IP_FOLDER_NAME and IP_FILE_NAME> TARGET=<TARGET SoC>
for example let's take RoboticArm with target shaktiz

> cd into shakti-sdk/software/examples/pwmmotor_v2/RoboticArm/output
check if the output file contains 3 files.
	- .dump
	- .o
	- .shakti

> run riscv64-unknown-elf-gdb

Here essentially you are opening up the debugger

> run set remotetimeout unlimited
> run taget remote :3333

then write this particular write address

> run x/wx 0x11300
next load the file

> run file pwmmotor_v2.c
> y
> load
> c

And now watch your code execute.

Case 2:

 - Create a folder and a file with the same name essentially
 - Copy the make file from a peripheral with greater similarity.

* In case of load errors move the load statement before the other
statements.*
